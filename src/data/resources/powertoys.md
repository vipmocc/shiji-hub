## 主要功能

- **窗口布局**：FancyZones 自定义分屏区域
- **批量重命名**：PowerRename 支持正则批量改名
- **取色/标尺/文本提取**：Color Picker、Screen Ruler、Text Extractor
- **20+ 实用工具**：按需开关，微软官方持续维护

## 适用人群

Windows 高级用户，想要系统级增强但不想装杂牌工具的人。

## 优缺点

- ✅ 微软官方出品，完全免费开源
- ✅ 每个模块独立开关，不强制全开
- ❌ 部分功能与其他第三方工具重叠，按需取舍
- ❌ 仅 Windows

## 使用建议

优先开启 FancyZones + PowerToys Run + 文本提取三件套，覆盖多数场景。

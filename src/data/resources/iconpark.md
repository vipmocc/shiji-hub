## 主要功能

- **2600+ 图标**：覆盖常见 UI 场景
- **多主题风格**：线性、填充、双色、多色一套图标多风格
- **多格式导出**：SVG/PNG/React/Vue 组件直接复制
- **Apache 2.0**：可免费商用（GitHub 仓库核实）

## 适用人群

UI 设计师、前端开发者找成套图标。
